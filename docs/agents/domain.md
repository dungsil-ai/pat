# 도메인 문서

이 저장소는 단일 컨텍스트 도메인 문서 구조를 사용합니다.

## 코드 탐색 전 확인할 문서

- 저장소 루트의 `CONTEXT.md`
- 저장소 루트에 `CONTEXT-MAP.md`가 있다면 그 문서가 가리키는 관련 `CONTEXT.md`
- 작업 영역과 관련된 `docs/adr/`의 ADR

문서가 없으면 별도 경고 없이 진행합니다. 도메인 용어나 결정이 실제로 필요해질 때 `vibe-modeling`이 문서를 점진적으로 생성합니다.

## 단일 컨텍스트 구조

```text
/
├── CONTEXT.md
├── docs/adr/
└── scripts/
```

## 사용 규칙

- 이슈 제목, 명세, 테스트 이름, 설계 설명에는 `CONTEXT.md`가 정의한 용어를 사용합니다.
- 용어집이 피하도록 정한 동의어를 새로 만들지 않습니다.
- 필요한 개념이 용어집에 없다면 기존 코드의 표현을 먼저 확인하고, 실제 도메인 공백일 때만 모델링 대상으로 기록합니다.
- 제안이나 구현이 기존 ADR과 충돌하면 해당 ADR을 명시하고 충돌 이유를 숨기지 않습니다.
