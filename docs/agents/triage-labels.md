# 라벨 매핑

스킬이 사용하는 표준 역할을 이 저장소의 실제 GitHub 라벨 문자열에 매핑합니다.

## 트리아지 상태

| 표준 역할 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `상태:분류필요` | 유지보수자의 분류와 판단이 필요함 |
| `needs-info` | `상태:정보필요` | 보고자의 추가 정보를 기다림 |
| `ready-for-agent` | `상태:에이전트작업` | 명세가 충분해 에이전트가 바로 작업 가능함 |
| `ready-for-human` | `상태:사람작업` | 사람이 직접 구현하거나 판단해야 함 |
| `wontfix` | `상태:처리안함` | 작업하지 않기로 결정함 |

`vibe-plan`이 표준 역할을 언급하면 이 표의 GitHub 라벨을 사용합니다.

## 계획 라벨

| 표준 역할 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| map | `상태:초안` | 구현 작업이 아닌 의사결정 지도의 인덱스 이슈 |
| research | `유형:조사` | 자료와 코드 조사를 통해 해결하는 결정 티켓 |
| prototype | `유형:프로토타입` | 폐기 가능한 프로토타입으로 해결하는 결정 티켓 |
| grilling | `유형:인터뷰` | 한 번에 한 질문씩 인터뷰해 해결하는 결정 티켓 |
| task | `유형:작업` | 결정을 내리기 전에 수행해야 하는 수동 작업 |

## 축 규칙

- `상태:`는 현재 상태를 나타냅니다.
- `유형:`은 결정 티켓의 해결 방식을 나타냅니다.
- 한 이슈에는 각 축의 라벨을 최대 하나만 적용합니다.
- `상태:초안`은 다른 `상태:` 라벨과 함께 쓰지 않습니다.
- 의사결정 지도와 그 결정 티켓은 요청 트리아지 대상이 아닙니다.
